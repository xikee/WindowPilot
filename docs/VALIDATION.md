## 尚未验证

当前运行环境未为应用授予辅助功能与屏幕录制权限。以下功能已实现，但尚未完成授权后的跨应用端到端验证：全局快捷键过滤、真实窗口枚举与截图、跨应用激活、最小化恢复、隐藏应用恢复、多个显示器与其他 Space 行为。

本地事件检查不能替代全局事件钩子测试；临时签名完整性检查也不代表开发者公证或 Gatekeeper 分发验证。因此首次发布标记为预览版。

## 复现

```bash
bash "scripts/test.sh"
bash "scripts/build.sh"
"dist/瞬切.app/Contents/MacOS/WindowPilot" --verify-ui ".build/ui-verification"
codesign --verify --strict --verbose=2 "dist/瞬切.app"
plutil -lint "dist/瞬切.app/Contents/Info.plist"
bash -n "scripts/build.sh" "scripts/test.sh"
```

授权后的手动验收建议：打开同一应用的两个窗口与另一应用的窗口，验证快速 `⌥ Tab` 往返、按住连续选择、反向选择、同应用筛选和搜索；最小化其中一个窗口后切换恢复；最后检查鼠标所在显示器和权限撤回后的行为。
